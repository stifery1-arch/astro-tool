解锁码生成器

给解读师用的本地工具：生成给客户的解锁码，并得到可以粘贴进 CONFIG.pay 的哈希数组。本页面不会联网。　→ 打开订单管理台（含收入统计）
① 发给客户的解锁码 （一码一用，发出后在表格里标注一下）
② 粘贴到 CONFIG.pay 的哈希数组
验证某个解锁码是否已在配置里生效
使用步骤
  1. 把这里的 hashSalt 改成你自己的（同时改 js/app.js 里的 CONFIG.pay.hashSalt，两边必须一致）。
  2. 生成一批解锁码，把 码列表 保存好（每个客户发一个）；把 哈希数组 粘贴进 CONFIG.pay.unlockHashes。
  3. 客户在小站上点付费导出 → 扫码付款 → 把订单号发给你 → 你发一个解锁码给他。
  4. 客户输入解锁码即解锁导出（下载图片 / 打印 PDF / 复制报告）。
  5. 如果做「一报告一码」：填上报告编号再生成，哈希贴进 CONFIG.pay.reportHashes，并把 mode 设为 report 或 both。
安全提示：源码里只保存哈希，无法反推出解锁码；但纯前端校验仍可能被技术用户绕过。正式经营建议用 server/pay-server.js 接入微信/支付宝官方支付，由服务端验签后自动解锁。
